# Project media

The typed media paths live in `data/projects.ts`. Add optimized files using this structure:

```text
public/projects/roamable/hero.webp
public/projects/roamable/screen-01.webp
public/projects/roamable/demo.mp4
public/projects/roamable/demo-poster.webp
public/projects/circadia/hero.webp
public/projects/circadia/prototype.webp
public/projects/circadia/demo.mp4
public/projects/circadia/demo-poster.webp
public/projects/ai-travel/hero.webp
```

Use WebP/AVIF for images. Keep short demo videos muted, compressed, and under a practical size; the media component uses metadata-only preload.
